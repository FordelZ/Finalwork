## Описание проекта

Проект содержит набор автоматизированных тестов для веб‑приложения пиццерии. Проверяемые сценарии:

- авторизация и регистрация пользователей;
- просмотр меню и выбор пиццы;
- добавление товаров в корзину;
- оформление заказа;
- оплата (включая тестовые платёжные данные);
- просмотр истории заказов.

## Технологии

- **Python** 3.8+ — язык реализации;
- **Selenium WebDriver** — взаимодействие с браузером;
- **PyTest** — фреймворк для запуска и организации тестов;
- **Allure** — генерация отчётов;
- **Page Object Model (POM)** — паттерн проектирования для структурирования кода;
- **pytest-html** — HTML‑отчёты;
- **pytest-xdist** — параллельное выполнение тестов (опционально).

## Запуск тестов

Ниже приведены основные команды для запуска автотестов в разных режимах.

### 1. Базовый запуск

Выполняет все тесты последовательно в обычном режиме (с отображением браузера).

```bash
pytest tests/
pytest --alluredir=allure-results tests/
allure serve allure-results
pytest -v --headless tests/
